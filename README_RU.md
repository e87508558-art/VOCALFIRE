# VOCALFIRE V1.0 Alpha — исходный проект

Это первый исходный прототип VST3-плагина для Windows и FL Studio.

## Что уже реализовано
- JUCE/CMake проект с целями VST3 и Standalone.
- Футуристичный интерфейс в чёрно-фиолетовой гамме.
- Параметры Input/Output, Low Cut, Reverb, Delay, Key, Scale и Pitch Amount.
- Сохранение состояния параметров проекта/пресета через JUCE APVTS.
- Простейший автокорреляционный pitch detector: показывает оценку ноты и частоты.

## Важное ограничение альфа-версии
Регулятор Pitch Amount и выбор Key/Scale уже присутствуют в интерфейсе и сохранении состояния, но **коррекция высоты тона (pitch shifting / auto-tune) ещё не подключена к аудиосигналу**. Сейчас реализовано только определение основной частоты для будущего Pitch Engine. Не следует считать это готовым Auto-Tune.

Reverb/Delay/Low Cut — начальные прототипы, не финальная студийная обработка.

## Сборка на Windows
Требования:
- Visual Studio 2022 с workload "Desktop development with C++"
- CMake 3.22+
- Git
- Интернет при первой конфигурации (CMake скачает JUCE 8.0.6)

Откройте x64 Native Tools Command Prompt или PowerShell в папке проекта:

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
```

После сборки ищите `VOCALFIRE.vst3` внутри `build` (точный путь зависит от генератора CMake).
Скопируйте bundle в:
`C:\Program Files\Common Files\VST3\`

Затем в FL Studio откройте Plugin Manager и выполните поиск новых плагинов.

## Следующие этапы разработки
1. Реализовать монофонический pitch correction с устойчивым трекингом F0.
2. Сделать scale quantizer с hysteresis и smoothing, чтобы нота не прыгала между ступенями.
3. Добавить качественный pitch shifter с formant preservation.
4. Добавить EQ, компрессор, de-esser и сатурацию.
5. Реализовать oversampling, latency reporting и корректную автоматизацию параметров.
6. Сделать тесты на разных голосах, частотах дискретизации и размерах буфера.

## Сборка без установки инструментов на свой ПК (через GitHub)

В проект добавлен workflow `.github/workflows/windows-vst3.yml`.
Он собирает VST3 на виртуальном Windows-компьютере GitHub Actions.

Краткий порядок:
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** в репозитории.
3. Выберите **Build VOCALFIRE VST3** и нажмите **Run workflow**.
4. После успешной сборки скачайте артефакт **VOCALFIRE-Windows-VST3**.
5. Из скачанного архива скопируйте `VOCALFIRE.vst3` в `C:\Program Files\Common Files\VST3\`.
6. В FL Studio откройте Plugin Manager и выполните поиск плагинов.

Это всё ещё исходный проект с автоматической облачной сборкой, а не уже собранный бинарный плагин.
Для загрузки на GitHub нужен аккаунт. Саму сборку нужно проверить в Actions: я не запускал её в этом окружении.

## Состав текущей альфа-версии
Сейчас реально обрабатывают звук Low Cut, Delay, Reverb и Input/Output Gain.
Компрессор, De-Esser, полноценный параметрический EQ, Saturation и Auto-Tune пока не реализованы.
Параметры Pitch/Key/Scale и индикатор высоты тона — заготовка для следующего этапа, не коррекция питча.
